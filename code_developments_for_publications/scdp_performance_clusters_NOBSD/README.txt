This directory contains a direct copy of the orthogonal rectangular version of the scdp_performance_cluster optimization.
However, adapted to allow for non-orthogonal building spatial designs (NOBSD).
The concept of deleting, splitting and scaling the spaces (as described in ) is applied in this version.

The main adaptation made to make this concept work for NOBSD:
- the splitting of a NOBSD space is done for the longest out of four axis. 
  the splitting function devides the opposing lines in the midle and defines a space.
