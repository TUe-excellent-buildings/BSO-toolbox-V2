Guide to the radiance-translation.cpp file:

Compile the file with the following terminal command: make radiance-translation

Run with ./radiance-translation <input_filename> <grid_filename> <output_filename>
	Example: ./radiance-translation design_301_PN grid output
	The "design_301_PN" is a design described in triangular prism text file
	The "grid" term will name the generated file containing the grid
	The "output" term will name the output file of the code
